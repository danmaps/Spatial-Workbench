Select by Attribute

Selects features using an attribute condition

Key
SelectByAttributeTool
Parameters
Name Type Description Default Options
Layer dropdown Layer to query — —
Field text Attribute field to query — —
Operator dropdown Attribute comparison equals equals, not equals, contains, starts with, ends with, greater than, less than, is empty, is not empty
Value text Value to compare — —
Selection Mode dropdown How to apply matching features replace replace, add, remove
Inputs / Outputs / State behavior

State mode: layers · Mutates state: yes · Produces artifacts: no

Inputs
  • Layer → layer · Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon
Outputs
  • selection → update
