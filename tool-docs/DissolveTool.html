Dissolve

Merges polygon features into a single boundary or groups them by a shared attribute field

Key
DissolveTool
Parameters
Name Type Description Default Options
Input Layer dropdown Polygon layer to dissolve — —
Dissolve Field text Attribute field to group by (leave empty to dissolve all) — —
Inputs / Outputs / State behavior

Inputs
  • Input Layer → layer · Polygon, MultiPolygon · honors selection
Outputs
  • layer → add · Polygon
