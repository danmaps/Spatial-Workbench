Compare

Compares two polygon layers (A vs B) and computes intersection, only-in-A, only-in-B, and area deltas

Parameters
Name Type Description Default Options

Layer B dropdown Comparison polygon layer (B) — —

  • Layer B → layer · Polygon, MultiPolygon
Outputs
  • layer → add · Polygon
