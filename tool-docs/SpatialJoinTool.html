Spatial Join

Joins attributes from a join layer onto a target layer by spatial predicate (intersects, within, or within_distance)

Key
SpatialJoinTool
Parameters
Name Type Description Default Options
Target Layer dropdown Target layer receiving joined attributes — —
Join Layer dropdown Source layer providing attributes to join — —
Predicate dropdown Spatial relationship predicate intersects intersects, within, within_distance
Distance float Search distance (for within_distance) 100 —
Units dropdown Distance units (for within_distance) meters feet, meters, miles, kilometers, degrees
Join Mode dropdown How matching join features are combined first_match first_match, summary
Inputs / Outputs / State behavior

State mode: layers · Mutates state: yes · Produces artifacts: no

Inputs
  • Target Layer → layer · Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon · honors selection
  • Join Layer → layer · Point, MultiPoint, LineString, MultiLineString, Polygon, MultiPolygon
Outputs
  • layer → add · Mixed
